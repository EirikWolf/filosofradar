description: Planlegg og gjennomfør neste uferdige fase i docs/PLAN.md
---

Finn første fase i `docs/PLAN.md` som ikke er ✅. $ARGUMENTS

1. Les fasen og relevante deler av `docs/PRD.md`, `docs/DESIGN.md`, `docs/DATAMODELL.md`
   og siste oppføringer i `docs/BESLUTNINGER.md`. Kjør `git status`.
2. Presenter planen – snakk til Olai:
   - hva vi skal lage, og hvorfor det blir kult (2–3 setninger)
   - nye begreper han kommer til å møte (maks 3, kort forklart)
   - filer som opprettes eller endres, og nye pakker med begrunnelse
   - hvordan vi sjekker at det virker
   - spørsmål om design- eller innholdsvalg han bør ta
3. **Stopp og vent** på «kjør».
4. Sett fasen til 🟨. Bygg i små steg. Etter hvert synlig delmål: si hvor i appen det kan sees,
   kjør `npm run check`, og commit.
5. Når alle kriterier er oppfylt: kryss av, sett ✅ med dato, oppdater dokumentene og loggfør valg.
6. Avslutt med: hva er nytt og hvor man ser det · fasens 🎯 «Din tur»-oppgave (uten fasit) ·
   hva neste fase handler om. Foreslå `/clear`.
